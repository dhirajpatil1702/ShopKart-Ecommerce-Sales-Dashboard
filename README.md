# ShopKart E-Commerce Sales Dashboard

## About the Project

An interactive e-commerce sales dashboard developed using Power BI and Excel to analyze sales performance and generate meaningful business insights.

## Tools & Technologies

- Power BI
- Excel
- Power Query
- DAX

## Key Analysis

- Total Sales
- Total Profit
- Total Quantity
- Total Orders
- Monthly Sales Trend
- Category-wise Sales
- State-wise Sales
- Discount Analysis

## Dashboard Features

- KPI Cards
- Interactive Slicers
- Sales Trend Analysis
- Category-wise Analysis
- State-wise Analysis
- Profit Analysis
